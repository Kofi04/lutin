Little Wizard

Un petit sorcier qui vit au-dessus de votre barre des tâches et met Claude à un clic, à propos de ce qui est à l'écran.

Télécharger pour Windows Voir sur GitHub

Version 0.2.0 · gratuit, licence MIT

Posez une question sur votre écran

Une zone, une fenêtre ou une image : la réponse apparaît en haut de l'écran.

Il vous montre le chemin

Le sorcier pointe les éléments à l'écran, étape par étape.

Vos sessions Claude Code

Approuvez leurs actions sans changer de fenêtre.

Nécessite Claude Code installé et connecté, sans clé API. L'installeur n'est pas encore signé : au premier lancement, Windows SmartScreen affichera un avertissement (Informations complémentaires → Exécuter quand même).
